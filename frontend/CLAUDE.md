# frontend — Next 16

Загальні правила проєкту й навчальний режим — у кореневому `CLAUDE.md`.
Дизайн-бриф на всі екрани — `../app-design.md`, читати перед роботою над UI.

## Стек

- Next 16 (App Router, Turbopack, `src/`) + React 19
- Tailwind 4
- TanStack Query 5 — серверний стан
- Zustand 5 — стан активного тренування
- react-hook-form + zod — форми
- openapi-fetch + openapi-typescript — клієнт до бекенду

## Конвенції

**Tailwind 4 налаштовується в CSS, не в JS.** Файлу `tailwind.config.ts`
немає і не треба. Кольори, шрифти й токени — через `@theme` у
`src/app/globals.css`.

**Типи API не писати руками.** Клієнт генерується з OpenAPI-схеми бекенду
через `openapi-typescript`. Якщо потрібного типу немає — перегенерувати схему,
а не дописувати інтерфейс уручну.

**Розподіл стану — не за звичкою, а за природою даних:**

- Дані з сервера (програми, історія, прогрес) — тільки TanStack Query.
  Не копіювати їх у `useState`.
- Активне тренування — один Zustand-стор. Це справжній локальний стан:
  він живе між екранами й існує до відправки на сервер.
- Стан одного компонента — звичайний `useState`.

**Серверні компоненти за замовчуванням.** `"use client"` додавати лише там,
де реально потрібні хуки, стан чи обробники подій — і якомога нижче по дереву.

**ID створює клієнт.** Новий підхід, тренування чи програма отримують UUIDv7
тут, до запиту на сервер. Причина — в кореневому `CLAUDE.md`.

## Обмеження інтерфейсу

Екран тренування використовується стоячи, однією рукою, спітнілими пальцями,
за кілька секунд між підходами. Для нього: великі цілі для пальця (мінімум
44px, а для головних кнопок — значно більше), читабельність з витягнутої руки,
мінімум тексту.

Решта екранів (програма, прогрес, історія, каталог) переглядаються спокійно
вдома — там доречні щільні списки, таблиці й великі графіки.

Це два різні режими, і виглядати вони мають по-різному.

## Команди

```bash
npm run dev       # http://localhost:3000
npm run build
npm run lint      # ESLint (на бекенді — oxlint, не плутати)
```

## Хто що пише

Розмітку (JSX) і стилі (Tailwind) пише асистент — повністю, без навчального
режиму. Логіку, пропси, хуки і стан пише Влад сам.

Повне формулювання, включно зі спірними випадками — розділ «Розподіл праці
на фронті» в кореневому `CLAUDE.md`.
